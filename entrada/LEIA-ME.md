# Pasta de entrada

Coloque aqui as fotos e vídeos para os próximos posts.

**Como enviar pelo site do GitHub (computador ou celular):**
1. Abra esta pasta no GitHub.
2. Clique em **Add file → Upload files**.
3. Arraste as fotos e vídeos e clique em **Commit changes**.

**Dicas:**
- Pode mandar do jeito que veio do WhatsApp; não precisa renomear.
- Se quiser, coloque uma palavra no nome do arquivo para indicar o assunto (ex.: `esteira-...mp4`, `ete-...jpg`).
- Pelo site, cada arquivo pode ter até 25 MB. Vídeos maiores: envie pelo chat do Claude.
- Lembre: esta pasta é **pública**. Não envie nada que não possa ir para o Instagram.

Depois de usados, os arquivos vão para a pasta `usado/`.
