# allcleantech-midia

Mídias e ferramentas dos posts do Instagram **@allcleantech**.

- `entrada/` — fotos e vídeos novos para os próximos posts (veja `entrada/LEIA-ME.md`)
- `usado/` — mídias já usadas
- `posts/` — artes e vídeos prontos, por data
- `marca/` — logo
- `ferramentas/` — gerador de carrossel e Reel (`render.py`) e fontes (licença OFL)
- `GUIA.md` — guia editorial, regras e rotina semanal

Repositório público: tudo aqui pode ser visto por qualquer pessoa.
